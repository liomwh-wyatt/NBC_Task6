# NBC_Task6

Unreal Engine C++로 구현한 멀티플레이어 숫자 야구 과제 프로젝트입니다.

## 게임 규칙

- 서버는 1부터 9까지 서로 다른 숫자 3개를 정답으로 생성합니다.
- 플레이어는 화면 아래 입력창에 숫자 3개를 입력하고 Enter 키로 제출합니다.
- 숫자와 위치가 모두 같으면 Strike, 숫자만 같으면 Ball, 모두 다르면 OUT입니다.
- 각 플레이어는 유효한 입력을 최대 3회까지 제출할 수 있습니다.
- 길이가 3이 아니거나, 숫자가 아니거나, 0 또는 중복 숫자가 포함된 입력은 기회를 소모하지 않습니다.
- 3 Strike를 먼저 맞힌 플레이어가 승리합니다.
- 모든 플레이어가 기회를 소진하면 무승부입니다.
- 승리 또는 무승부 후 시도 횟수와 정답이 초기화됩니다.

## 구현 내용

- 채팅 입력을 Server RPC로 전달하고 결과를 각 클라이언트에 Client RPC로 출력
- 서버의 숫자 생성, 입력 검증, Strike/Ball/OUT 판정
- `PlayerState`를 이용한 플레이어 이름과 현재/최대 시도 횟수 복제
- 승리·무승부 판정과 게임 초기화
- 복제된 결과 문구를 표시하는 알림 위젯

## 개발 환경

- Unreal Engine 5.7
- Visual Studio 2022
- Windows 64-bit

## 실행

1. `NumBas.uproject`를 Unreal Engine 5.7로 엽니다.
2. 에디터에서 `L_Chatting` 맵을 엽니다.
3. 플레이 설정에서 클라이언트 수를 2로 설정하고 별도 서버를 실행합니다.
4. 각 클라이언트 화면 아래 입력창에 숫자를 입력하고 Enter 키를 누릅니다.

## 주요 클래스

- `ANBGameModeBase`: 정답 생성, 입력 검증, 판정, 승패 및 게임 초기화
- `ANBPlayerController`: 채팅 RPC, 결과 출력, 알림 위젯 생성 및 문구 복제
- `ANBPlayerState`: 플레이어 이름과 시도 횟수 관리
- `UNBChatInput`: 채팅 입력 위젯의 Enter 입력 처리
